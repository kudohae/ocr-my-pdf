# PDF OCR

스캔 PDF를 업로드하면 검색과 텍스트 복사가 가능한 PDF로 변환하는 작은 웹앱입니다. OCRmyPDF와 Tesseract의 `tessdata_best` 한국어·영어 모델을 사용하고, 페이지 방향과 기울기를 자동 보정합니다. 이미 텍스트가 있는 페이지는 건너뜁니다.

## 실행

Docker가 설치된 환경에서:

```sh
docker build -t pdf-ocr .
docker run --rm -p 8000:8000 pdf-ocr
```

브라우저에서 <http://localhost:8000>을 엽니다. PDF를 선택하고 언어를 고른 뒤 **OCR 시작**을 누르면 결과 PDF가 다운로드됩니다.

업로드 제한은 100 MB, 작업 시간 제한은 15분입니다. 업로드와 결과 파일은 요청별 임시 디렉터리에 보관하고 응답 완료 후 삭제합니다. 서버 재시작 등으로 작업이 갑자기 종료되면 임시 파일이 남을 수 있으므로 운영 환경에서는 임시 디렉터리를 주기적으로 정리하세요.

OCR 정확도는 원본 스캔 품질에 좌우됩니다. 흐린 이미지, 손글씨, 복잡한 표는 결과를 확인해야 합니다. 공개 인터넷에 배포할 때는 앞단에 인증과 요청 제한을 두세요.
